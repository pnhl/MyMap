# MyMap

MyMap is an Expo + React Native mapping application.

This repository is being initialized with an automated GitHub Actions bootstrap so the project can be built on GitHub-hosted macOS and packaged as `MyMap-Firebase-XCTest.zip` for Firebase Test Lab.

The public repository intentionally does **not** commit real Firebase service configuration or local `.env` secrets. CI uses non-secret placeholder Firebase configuration only for the XCTest build pipeline.
